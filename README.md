## About

I am **Ali Zafar**, an **AI Automation Engineer** and **Applied AI / LLM Systems Builder** focused on building practical AI products, automation workflows, SaaS backends, and DevOps-ready infrastructure.

My work combines **software engineering**, **applied AI**, **workflow automation**, and **cloud-native deployment**. I build systems using **FastAPI**, **Python**, **PostgreSQL**, **Redis/Celery**, **Docker**, **GitHub Actions**, **Kubernetes/Minikube**, **RAG pipelines**, **LLM agents**, **CRM automations**, and **voice AI workflows**.

I focus on engineering systems that are structured beyond the demo stage: **tenant isolation**, **safe tool use**, **structured logging**, **background jobs**, **billing enforcement**, **webhook reliability**, **health checks**, **CI/CD validation**, **monitoring**, **rollback planning**, and operational documentation.
